# Agent Guidance

Read and follow the applicable guidance:

- **Decisions:** every task, including explanation-only work → [decisions and reporting](CODING_STANDARDS.md#decisions).
- **Domain:** before exploring → [domain guidance](docs/agents/domain.md).
- **Requests:** fetching, creating, or updating → [issue tracker](docs/agents/issue-tracker.md).
- **Triage:** applying roles → [label mappings](docs/agents/triage-labels.md).
- **Changes:** code or documentation, including docs-only edits → [changes and verification](CODING_STANDARDS.md#changes).
- **Milestones:** planning or execution → [milestone workflow](CODING_STANDARDS.md#milestones).
- **Delivery:** commits, PRs, pushes, tags, or release execution → [delivery requirements](CODING_STANDARDS.md#delivery).
- **Releases:** writing handoffs → [executor requirements](CODING_STANDARDS.md#releases).
