# DeltaScope v0.34.0 Release Notes

## Summary

DeltaScope v0.34.0 is the **PostgreSQL Generated/Identity Narrow Support Pack**. Narrow generated/identity definition forms are now processed through the normal supported audit path instead of returning `ErrUnsupportedStatement`.

This is narrow support widening — not full generated-column support, not full identity-column support, not generated expression evaluation, not complete PostgreSQL sequence semantics, and not state-transition support.

## What Changed

The PostgreSQL extractor no longer rejects narrow generated/identity definition forms at the unsupported boundary. These forms now enter the normal normalization and rule evaluation path, producing standard audit results with findings where applicable.

### Supported Forms

The following PostgreSQL forms are now supported (no longer return `ErrUnsupportedStatement`):

| Form | Example |
|------|---------|
| `CREATE TABLE` generated stored | `CREATE TABLE t (full_name text GENERATED ALWAYS AS (first_name) STORED)` |
| `CREATE TABLE` identity | `CREATE TABLE t (id bigint GENERATED ALWAYS AS IDENTITY)` |
| `CREATE TABLE` identity with options | `CREATE TABLE t (id bigint GENERATED BY DEFAULT AS IDENTITY (START WITH 10 INCREMENT BY 5 CACHE 20 CYCLE))` |
| `ALTER TABLE ADD COLUMN` generated stored | `ALTER TABLE t ADD COLUMN full_name text GENERATED ALWAYS AS (first_name) STORED` |
| `ALTER TABLE ADD COLUMN` identity | `ALTER TABLE t ADD COLUMN id bigint GENERATED ALWAYS AS IDENTITY` |

### Preserved Facts

Shared facts from v0.33.0 continue flowing through the supported path:

| Fact | Type | Description |
|------|------|-------------|
| `generated_when` | string | `"a"` (ALWAYS) or `"d"` (BY DEFAULT) |
| `is_identity` | bool | `true` for identity columns |
| `identity_options` | map | Finite structured sequence option facts (`start`, `increment`, `minvalue`, `maxvalue`, `cache`, `cycle`) |

`GeneratedExpression` is not part of the contract — no expression text is preserved.

### What Remains Unsupported

State-transition forms continue to return `ErrUnsupportedStatement`:

| Form | Unsupported Feature |
|------|-------------------|
| `ALTER TABLE ... ALTER COLUMN ... DROP EXPRESSION` | `generated_column` |
| `ALTER TABLE ... ALTER COLUMN ... SET GENERATED ...` | `generated_as_identity` |
| `ALTER TABLE ... ALTER COLUMN ... DROP IDENTITY` | `generated_as_identity` |

### What Did Not Change

- No new rule IDs.
- No new CLI flags.
- No rule behavior changes.
- No generated expression evaluation.
- No complete PostgreSQL sequence semantics.
- The supported path is extractor-level widening only.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/Fanduzi/DeltaScope/v0.34.0/install.sh | \
  DELTASCOPE_VERSION=v0.34.0 sh
```
