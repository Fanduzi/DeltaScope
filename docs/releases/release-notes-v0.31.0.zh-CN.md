# DeltaScope v0.31.0 发行说明

发布日期：2026-04-14

## 概述

DeltaScope `v0.31.0` 是 **PostgreSQL ALTER TABLE GENERATED 后续边界包**。它将额外的 PostgreSQL generated/identity `ALTER TABLE` 形态映射到显式 unsupported feature 标签。这是边界收紧——不代表 generated-column 支持、identity-column 支持，也不代表完整的 PostgreSQL `ALTER TABLE` 支持。

## 变更内容

`v0.30.0` 已将 PostgreSQL `ALTER TABLE ... ADD COLUMN` 的 generated/identity 形态锁定为显式 unsupported feature。`v0.31.0` 收紧了 `v0.30.0` 故意保留在 generic unsupported 边界上的相邻 generated/identity alteration 形态：

```sql
ALTER TABLE users ALTER COLUMN full_name DROP EXPRESSION;
ALTER TABLE users ALTER COLUMN id SET GENERATED BY DEFAULT;
ALTER TABLE users ALTER COLUMN id DROP IDENTITY;
```

这些语句现在会返回显式 unsupported 结果，而不是 generic AST-subtype 名称。

## 精确 Unsupported 映射

| 形态 | unsupported feature |
|------|---------------------|
| `ALTER TABLE ... ALTER COLUMN ... DROP EXPRESSION` | `generated_column` |
| `ALTER TABLE ... ALTER COLUMN ... SET GENERATED ...` | `generated_as_identity` |
| `ALTER TABLE ... ALTER COLUMN ... DROP IDENTITY` | `generated_as_identity` |

### v0.30.0 上下文（已锁定）

| 形态 | unsupported feature |
|------|---------------------|
| `ALTER TABLE ... ADD COLUMN ... GENERATED ALWAYS AS (...) STORED` | `generated_column` |
| `ALTER TABLE ... ADD COLUMN ... GENERATED ALWAYS AS IDENTITY` | `generated_as_identity` |

## Surface 契约

各传输面的行为继续与既有 unsupported 契约保持一致：

- **CLI** 和 **`pkg/deltascope`** 返回带 `unsupported` 数组的部分结果，以及 `ErrUnsupportedStatement`。
- **HTTP** 和 **MCP** 将不支持语句作为传输层错误暴露，因为底层审计调用会返回错误。

本次发布在所有置信度层面锁定了这套边界契约：

- 每个新边界形态的 SQL 语料覆盖
- Service 层 table-driven 检查
- CLI、HTTP、MCP 和 `pkg/deltascope` 的表面对等

## 未变更内容

- DeltaScope 未将 generated expression 或 identity 语义建模为受支持的能力。
- DeltaScope 不支持 generated-column alteration。
- DeltaScope 不支持 identity-column alteration。
- DeltaScope 不提供完整的 PostgreSQL `ALTER TABLE` 支持。
- 未新增 rule ID、CLI 标志或公共 API 类型。
- 未更改 parser dependency 或 package version。
- MySQL 和 TiDB 的审核行为不变。
- `v0.26.0` 中 PostgreSQL `CREATE TABLE` 的 unsupported 边界仍然有效。
- `v0.30.0` 中 PostgreSQL `ALTER TABLE ... ADD COLUMN` 的 unsupported 边界仍然有效。

## 后续 / 下一步决策

- 决定后续 PostgreSQL 边界工作是否应为更多 alter-table 形态（如 `ALTER COLUMN ... SET DATA TYPE`、`ALTER COLUMN ... RESTART`）深化显式 unsupported 子类型，还是继续使用 generic unsupported 契约。
- 以后再决定这些显式 unsupported 边界是否应演进为真正的 generated-column 或 identity-column 支持。

## 安装 / 升级

```bash
# macOS（推荐）
brew tap Fanduzi/deltascope
brew install --cask deltascope

# 通用安装脚本
curl -fsSL https://raw.githubusercontent.com/Fanduzi/DeltaScope/v0.31.0/install.sh | \
  DELTASCOPE_VERSION=v0.31.0 sh
```
