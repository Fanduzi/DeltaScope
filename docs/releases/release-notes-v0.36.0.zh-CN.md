# DeltaScope v0.36.0 发行说明

## 概述

DeltaScope v0.36.0 是 **PostgreSQL Generated/Identity Rule Coverage Pack**。三条新的 PostgreSQL-only forbid 规则覆盖了 v0.35.0 已支持的 generated/identity 状态转换形态，使这些形态产生明确的 `rule_id` findings，不再静默通过。

这是规则覆盖——不是 parser 支持范围扩展、不是 spec 契约扩展、不是 generated expression 求值、不是完整的 PostgreSQL 序列语义。

## 变更内容

### 新增规则覆盖

三条 PostgreSQL-only forbid alter-action 规则现已注册：

| Rule ID | Action | 覆盖形态 |
|---------|--------|---------|
| `ddl.alter.drop_expression.forbid` | `drop_expression` | `ALTER TABLE ... ALTER COLUMN ... DROP EXPRESSION` |
| `ddl.alter.set_generated.forbid` | `set_generated` | `ALTER TABLE ... ALTER COLUMN ... SET GENERATED ...` |
| `ddl.alter.drop_identity.forbid` | `drop_identity` | `ALTER TABLE ... ALTER COLUMN ... DROP IDENTITY` |

这些规则使用现有的 `newForbiddenAlterActionRule` 构造器加 PostgreSQL-only 方言白名单——与已有的 5 条 PG-native alter action forbid 规则（`set_data_type`、`set_default`、`drop_default`、`set_not_null`、`drop_not_null`）采用相同模式。

### 表面覆盖

CLI、HTTP、MCP 和 `pkg/deltascope` 四条产品面现在为这些形态产生明确的 `rule_id` findings。示例 JSON 结构：

```json
{
  "findings": [
    {
      "rule_id": "ddl.alter.set_generated.forbid",
      "level": "blocker",
      "message": "ALTER action 'set_generated' is not allowed"
    }
  ]
}
```

### 已覆盖的状态转换形态

| 形态 | Rule ID |
|------|---------|
| `ALTER TABLE ... ALTER COLUMN ... DROP EXPRESSION` | `ddl.alter.drop_expression.forbid` |
| `ALTER TABLE ... ALTER COLUMN ... SET GENERATED ALWAYS` | `ddl.alter.set_generated.forbid` |
| `ALTER TABLE ... ALTER COLUMN ... SET GENERATED BY DEFAULT` | `ddl.alter.set_generated.forbid` |
| `ALTER TABLE ... ALTER COLUMN ... DROP IDENTITY` | `ddl.alter.drop_identity.forbid` |

### 未变更的部分

- 无 parser 支持范围扩展——状态转换形态已在 v0.35.0 支持。
- 无 spec 契约扩展——无新增 spec 字段。
- 无 generated expression 求值。
- 无完整 PostgreSQL 序列语义。
- 无 MySQL/TiDB 行为变更。
- 无新增 CLI 标志。

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/Fanduzi/DeltaScope/v0.36.0/install.sh | \
  DELTASCOPE_VERSION=v0.36.0 sh
```
