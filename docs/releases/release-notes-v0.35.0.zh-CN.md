# DeltaScope v0.35.0 发行说明

## 概述

DeltaScope v0.35.0 是 **PostgreSQL Generated/Identity State-Transition Pack**。PostgreSQL generated 和 identity 列的状态转换形态现在通过正常审核路径支持，不再返回 `ErrUnsupportedStatement`。

这是状态转换支持——不是完整的 generated-column 生命周期支持、不是 generated expression 求值、不是完整的 PostgreSQL 序列语义，也没有新增 rule ID。

## 变更内容

PostgreSQL 提取器不再在 unsupported 边界处拒绝状态转换形态。这些形态现在进入正常的标准化和规则评估路径，在适用时产生标准审核结果和 findings。

### 已支持形态

以下 PostgreSQL 状态转换形态现在已被支持（不再返回 `ErrUnsupportedStatement`）：

| 形态 | 示例 |
|------|------|
| `ALTER TABLE ... ALTER COLUMN ... DROP EXPRESSION` | `ALTER TABLE t ALTER COLUMN full_name DROP EXPRESSION` |
| `ALTER TABLE ... ALTER COLUMN ... SET GENERATED ALWAYS` | `ALTER TABLE t ALTER COLUMN full_name SET GENERATED ALWAYS` |
| `ALTER TABLE ... ALTER COLUMN ... SET GENERATED BY DEFAULT` | `ALTER TABLE t ALTER COLUMN full_name SET GENERATED BY DEFAULT` |
| `ALTER TABLE ... ALTER COLUMN ... DROP IDENTITY` | `ALTER TABLE t ALTER COLUMN id DROP IDENTITY` |

### 标准化契约

这些形态产生共享 spec 事实，供审核管线消费：

| Action | Options |
|--------|---------|
| `drop_expression` | — |
| `set_generated` | `generated_when`：`"a"`（ALWAYS）或 `"d"`（BY DEFAULT） |
| `drop_identity` | — |

### 仍然 Unsupported 的形态

- 超出上述形态的完整 generated-column 生命周期支持。
- Generated expression 求值（不保留表达式文本）。
- 完整的 PostgreSQL 序列语义。

### 未变更的部分

- 无新增 rule ID。
- 无新增 CLI 标志。
- 无规则行为变更。
- 无 MySQL/TiDB 行为变更。
- 无 generated expression 求值。

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/Fanduzi/DeltaScope/v0.35.0/install.sh | \
  DELTASCOPE_VERSION=v0.35.0 sh
```
