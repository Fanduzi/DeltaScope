# DeltaScope v0.33.0 发行说明

## 概述

DeltaScope v0.33.0 是 **PostgreSQL Generated/Identity 事实保留 + Unsupported Metadata 展示包**。它在共享 DDL 契约中保留窄范围 generated/identity 列事实，并在不支持的 generated/identity 结果上展示结构化 metadata——不新增 generated-column 支持、identity-column 支持、表达式求值，也不改变任何规则行为。

## 变更内容

### 共享契约字段

`spec.Column` 新增 `omitempty` 字段：

| 字段 | 类型 | 取值 | 来源 |
|------|------|------|------|
| `GeneratedWhen` | string | `"a"`（ALWAYS）、`"d"`（BY DEFAULT）、`""`（非生成列） | PostgreSQL `GENERATED ALWAYS AS` / `GENERATED BY DEFAULT AS` |
| `IsIdentity` | bool | identity 列为 `true`，其他省略 | PostgreSQL `CONSTR_IDENTITY` 约束类型 |
| `IdentityOptions` | map[string]any | 数值选项为整数，`cycle` 为布尔值 | PostgreSQL identity 序列选项（`START`、`INCREMENT`、`MINVALUE`、`MAXVALUE`、`CACHE`、`CYCLE`） |

这些字段同时适用于 `CREATE TABLE` 和 `ALTER TABLE ADD COLUMN` 的 generated/identity 路径。`GeneratedExpression`（`GENERATED ALWAYS AS (...) STORED` 的计算表达式）已明确延迟——当前 `pg_query_go` 依赖中没有稳定的表达式渲染器。

### Unsupported Metadata

`UnsupportedDetail` 现在为不支持的 generated/identity 结果携带 `Metadata map[string]any` 字段：

**Generated 列 metadata（`generated_column`）：**

| 键 | 类型 | 示例 |
|----|------|------|
| `column` | string | `"full_name"` |
| `generated_when` | string | `"a"` |

**Identity 列 metadata（`generated_as_identity`）：**

| 键 | 类型 | 示例 |
|----|------|------|
| `column` | string | `"id"` |
| `generated_when` | string | `"a"` 或 `"d"` |
| `is_identity` | bool | `true` |
| `identity_options` | object | `{"start": 10, "increment": 5, "minvalue": 1, "maxvalue": 9999, "cache": 20, "cycle": true}` |

`identity_options` 是有限结构化事实集合——不是完整的 PostgreSQL sequence 语义。只保留出现在 SQL 文本中的六个选项。

### Surface 契约

| Surface | Unsupported Metadata 可见性 |
|---------|---------------------------|
| CLI（JSON） | `unsupported[0].metadata` 对象在 JSON 输出中可见 |
| pkg/deltascope | `result.Unsupported[i].Metadata` 可直接作为类型化 `map[string]any` 访问 |
| HTTP | Metadata 通过 captured result 可用；传输层返回 unsupported 错误 |
| MCP | **限制**：metadata 当前未直接展示。MCP 工具返回 `IsError=true` 及错误 code/message。MCP 消费者访问 metadata 需要未来的 surface 变更。 |

### 未变更内容

- 无新增 rule ID 或规则行为变更。
- 无新增 CLI 标志或公共 API 契约（除上列 additive 字段外）。
- Unsupported feature 名称不变：`generated_column`、`generated_as_identity`。
- ALTER TABLE 状态转换形式（`DROP EXPRESSION`、`SET GENERATED`、`DROP IDENTITY`）保持不支持且不携带 metadata。
- `GeneratedExpression` 已延迟——不保留表达式文本。
- MySQL/TiDB 行为不受影响。
- Corpus、service 和 surface parity 测试在四条传输通道上锁定新契约。

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/Fanduzi/DeltaScope/v0.33.0/install.sh | \
  DELTASCOPE_VERSION=v0.33.0 sh
```

或通过 Homebrew：

```bash
brew tap Fanduzi/deltascope
brew install --cask deltascope
```

## 后续方向

- 在 `pg_query_go` 提供稳定的表达式反编译路径或设计窄范围自定义渲染器后，决定是否处理 `GeneratedExpression`。
- 决定 ALTER TABLE 状态转换形式是否应获得与 CREATE TABLE 和 ADD COLUMN 类似的 metadata 展示。
