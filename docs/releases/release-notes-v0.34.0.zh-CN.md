# DeltaScope v0.34.0 发行说明

## 概述

DeltaScope v0.34.0 是 **PostgreSQL Generated/Identity Narrow Support 包**。窄范围 generated/identity 定义形态现在通过正常支持路径审核，不再返回 `ErrUnsupportedStatement`。

这是窄范围支持扩展——不是完整的 generated-column 支持、不是完整的 identity-column 支持、不是 generated expression 求值、不是完整的 PostgreSQL 序列语义，也不是状态转换支持。

## 变更内容

PostgreSQL 提取器不再在 unsupported 边界处拒绝窄范围 generated/identity 定义形态。这些形态现在进入正常的标准化和规则评估路径，在适用时产生标准审核结果和 findings。

### 已支持形态

以下 PostgreSQL 形态现在已被支持（不再返回 `ErrUnsupportedStatement`）：

| 形态 | 示例 |
|------|------|
| `CREATE TABLE` generated stored | `CREATE TABLE t (full_name text GENERATED ALWAYS AS (first_name) STORED)` |
| `CREATE TABLE` identity | `CREATE TABLE t (id bigint GENERATED ALWAYS AS IDENTITY)` |
| `CREATE TABLE` 带选项 identity | `CREATE TABLE t (id bigint GENERATED BY DEFAULT AS IDENTITY (START WITH 10 INCREMENT BY 5 CACHE 20 CYCLE))` |
| `ALTER TABLE ADD COLUMN` generated stored | `ALTER TABLE t ADD COLUMN full_name text GENERATED ALWAYS AS (first_name) STORED` |
| `ALTER TABLE ADD COLUMN` identity | `ALTER TABLE t ADD COLUMN id bigint GENERATED ALWAYS AS IDENTITY` |

### 保留事实

v0.33.0 引入的共享事实继续在已支持路径中流转：

| 事实 | 类型 | 描述 |
|------|------|------|
| `generated_when` | string | `"a"`（ALWAYS）或 `"d"`（BY DEFAULT） |
| `is_identity` | bool | identity 列为 `true` |
| `identity_options` | map | 有限结构化序列选项事实（`start`、`increment`、`minvalue`、`maxvalue`、`cache`、`cycle`） |

`GeneratedExpression` 不属于此契约——不保留表达式文本。

### 仍然 Unsupported 的形态

状态转换形态继续返回 `ErrUnsupportedStatement`：

| 形态 | Unsupported Feature |
|------|-------------------|
| `ALTER TABLE ... ALTER COLUMN ... DROP EXPRESSION` | `generated_column` |
| `ALTER TABLE ... ALTER COLUMN ... SET GENERATED ...` | `generated_as_identity` |
| `ALTER TABLE ... ALTER COLUMN ... DROP IDENTITY` | `generated_as_identity` |

### 未变更的部分

- 无新增 rule ID。
- 无新增 CLI 标志。
- 无规则行为变更。
- 无 generated expression 求值。
- 无完整的 PostgreSQL 序列语义。
- 已支持路径仅为提取器层的范围扩展。

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/Fanduzi/DeltaScope/v0.34.0/install.sh | \
  DELTASCOPE_VERSION=v0.34.0 sh
```
