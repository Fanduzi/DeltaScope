# DeltaScope v0.35.0 Release Notes

## Summary

DeltaScope v0.35.0 is the **PostgreSQL Generated/Identity State-Transition Pack**. State-transition forms for PostgreSQL generated and identity columns are now supported through the normal audit path instead of returning `ErrUnsupportedStatement`.

This is state-transition support — not full generated-column lifecycle support, not generated expression evaluation, not complete PostgreSQL sequence semantics, and no new rule IDs.

## What Changed

The PostgreSQL extractor no longer rejects state-transition forms at the unsupported boundary. These forms now enter the normal normalization and rule evaluation path, producing standard audit results with findings where applicable.

### Supported Forms

The following PostgreSQL state-transition forms are now supported (no longer return `ErrUnsupportedStatement`):

| Form | Example |
|------|---------|
| `ALTER TABLE ... ALTER COLUMN ... DROP EXPRESSION` | `ALTER TABLE t ALTER COLUMN full_name DROP EXPRESSION` |
| `ALTER TABLE ... ALTER COLUMN ... SET GENERATED ALWAYS` | `ALTER TABLE t ALTER COLUMN full_name SET GENERATED ALWAYS` |
| `ALTER TABLE ... ALTER COLUMN ... SET GENERATED BY DEFAULT` | `ALTER TABLE t ALTER COLUMN full_name SET GENERATED BY DEFAULT` |
| `ALTER TABLE ... ALTER COLUMN ... DROP IDENTITY` | `ALTER TABLE t ALTER COLUMN id DROP IDENTITY` |

### Normalized Contract

These forms produce shared spec facts consumed by the audit pipeline:

| Action | Options |
|--------|---------|
| `drop_expression` | — |
| `set_generated` | `generated_when`: `"a"` (ALWAYS) or `"d"` (BY DEFAULT) |
| `drop_identity` | — |

### What Remains Unsupported

- Full generated-column lifecycle support beyond the forms listed above.
- Generated expression evaluation (expression text is not preserved).
- Complete PostgreSQL sequence semantics.

### What Did Not Change

- No new rule IDs.
- No new CLI flags.
- No rule behavior changes.
- No MySQL/TiDB behavior changes.
- No generated expression evaluation.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/Fanduzi/DeltaScope/v0.35.0/install.sh | \
  DELTASCOPE_VERSION=v0.35.0 sh
```
