# DeltaScope v0.33.0 Release Notes

## Summary

DeltaScope v0.33.0 is the **PostgreSQL Generated/Identity Fact Preservation + Unsupported Metadata Surfacing Pack**. It preserves narrow generated/identity column facts in the shared DDL contract and surfaces structured metadata on unsupported generated/identity outcomes — without adding generated-column support, identity-column support, expression evaluation, or any rule behavior changes.

## What Changed

### Shared Contract Fields

New `omitempty` fields on `spec.Column`:

| Field | Type | Values | Source |
|-------|------|--------|--------|
| `GeneratedWhen` | string | `"a"` (ALWAYS), `"d"` (BY DEFAULT), `""` (not generated) | PostgreSQL `GENERATED ALWAYS AS` / `GENERATED BY DEFAULT AS` |
| `IsIdentity` | bool | `true` for identity columns, omitted otherwise | PostgreSQL `CONSTR_IDENTITY` constraint type |
| `IdentityOptions` | map[string]any | Numeric options as integers, `cycle` as boolean | PostgreSQL identity sequence options (`START`, `INCREMENT`, `MINVALUE`, `MAXVALUE`, `CACHE`, `CYCLE`) |

These fields apply to both `CREATE TABLE` and `ALTER TABLE ADD COLUMN` generated/identity paths. `GeneratedExpression` (the computed expression for `GENERATED ALWAYS AS (...) STORED`) is deferred — there is no stable expression renderer available in the current `pg_query_go` dependency.

### Unsupported Metadata

`UnsupportedDetail` now carries a `Metadata map[string]any` field for unsupported generated/identity outcomes:

**Generated column metadata (`generated_column`):**

| Key | Type | Example |
|-----|------|---------|
| `column` | string | `"full_name"` |
| `generated_when` | string | `"a"` |

**Identity column metadata (`generated_as_identity`):**

| Key | Type | Example |
|-----|------|---------|
| `column` | string | `"id"` |
| `generated_when` | string | `"a"` or `"d"` |
| `is_identity` | bool | `true` |
| `identity_options` | object | `{"start": 10, "increment": 5, "minvalue": 1, "maxvalue": 9999, "cache": 20, "cycle": true}` |

`identity_options` is a finite structured fact bag — not complete PostgreSQL sequence semantics. Only the six options that appear in the SQL text are preserved.

### Surface Contract

| Surface | Unsupported Metadata Visibility |
|---------|-------------------------------|
| CLI (JSON) | `unsupported[0].metadata` object visible in JSON output |
| pkg/deltascope | `result.Unsupported[i].Metadata` directly accessible as typed `map[string]any` |
| HTTP | Metadata available via captured result; transport returns unsupported error |
| MCP | **Limitation**: metadata is not directly surfaced. The MCP tool returns `IsError=true` with error code/message only. Metadata access for MCP consumers requires a future surface change. |

### What Did Not Change

- No new rule IDs or rule behavior changes.
- No new CLI flags or public API contracts beyond the additive fields listed above.
- Unsupported feature names remain unchanged: `generated_column`, `generated_as_identity`.
- ALTER TABLE state-transition forms (`DROP EXPRESSION`, `SET GENERATED`, `DROP IDENTITY`) remain unsupported without metadata.
- `GeneratedExpression` is deferred — no expression text is preserved.
- MySQL/TiDB behavior is unaffected.
- Corpus, service, and surface parity tests lock the new contract across all four transport surfaces.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/Fanduzi/DeltaScope/v0.33.0/install.sh | \
  DELTASCOPE_VERSION=v0.33.0 sh
```

Or via Homebrew:

```bash
brew tap Fanduzi/deltascope
brew install --cask deltascope
```

## Next Follow-up

- Decide whether ALTER TABLE state-transition forms should receive metadata surfacing similar to CREATE TABLE and ADD COLUMN.
