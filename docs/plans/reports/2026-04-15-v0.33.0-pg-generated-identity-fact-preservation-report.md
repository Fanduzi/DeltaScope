## Generated Expression Decision

**Decision: Defer `GeneratedExpression` from v0.33.0 production.**

Evidence:

1. `RawExpr` is a `*pg_query.Node_AExpr` containing stable column refs (`first_name`, `last_name`) and string literals (` `). The tree structure is deterministic and walkable.
2. `pg_query_go/v6` does **not** expose `DeparseExpr`. Only `pg_query.Deparse(*ParseResult)` exists, which operates on a full parse result, not an individual expression node.
3. There is no existing deparse/render helper in the codebase. The only expression-related code is `collectColumnRefs` in `extractor.go`, which walks for column names but does not render SQL.
4. Writing a custom expression renderer would create a long-term public contract for expression text, which is high risk for correctness and maintenance.

Conclusion for Task 2: Do **not** implement `GeneratedExpression` in v0.33.0. The expression AST is available if a future milestone provides a stable deparse path.

## Identity Options Decision

**Decision: Allow `IdentityOptions` into Task 2 with full option coverage.**

Evidence:

1. All numeric options are `int32` via `DefElem.arg.Integer.Ival`: `start=10`, `increment=5`, `minvalue=1`, `maxvalue=9999`, `cache=20`.
2. `CYCLE` is a `Boolean` node with `Boolval=true`. This is boolean-safe and can be normalized to `map[string]any{"cycle": true}`.
3. All 6 tested options (`start`, `increment`, `minvalue`, `maxvalue`, `cache`, `cycle`) have stable, typed values that normalize cleanly into `map[string]any`.
4. The `DefElem.defname` values are lowercase and deterministic.
5. `CREATE TABLE` and `ALTER TABLE ADD COLUMN` produce identical option shapes (confirmed by v0.32.0 tests).

Conclusion for Task 2: Implement `IdentityOptions map[string]any` with integer values for numeric options and boolean value for `cycle`.

Conclusion for Task 2: Add `Metadata map[string]any` to `UnsupportedDetail` and populate it for generated/identity unsupported paths.

## Approved Production Scope For Task 2

**Safe narrow facts + IdentityOptions:**

- `GeneratedWhen string` — stable `"a"` / `"d"` encoding
- `IsIdentity bool` — stable boolean for CONSTR_IDENTITY
- `IdentityOptions map[string]any` — stable integer + boolean option map
- `UnsupportedDetail.Metadata map[string]any` — additive metadata for unsupported generated/identity outcomes

This is between "safe narrow facts" and "full narrow facts". `GeneratedExpression` is deferred because there is no stable renderer. `IdentityOptions` is promoted because all tested options have stable, typed values.
