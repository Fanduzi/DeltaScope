# v0.33.0 PostgreSQL Generated/Identity Fact Preservation + Unsupported Metadata Surfacing Pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve PostgreSQL generated/identity column facts in shared specs and expose the same facts through unsupported-result metadata while keeping generated/identity statements unsupported.

**Architecture:** Start with a decision gate for expression rendering, identity option normalization, and unsupported metadata shape. Then add additive `omitempty` contract fields, populate them in the PostgreSQL extractor for `CREATE TABLE` and `ALTER TABLE ADD COLUMN`, widen unsupported metadata, lock corpus/service/surface parity, and update release docs. Do not change rule behavior or remove unsupported outcomes.

**Tech Stack:** Go, `pg_query_go/v6`, DeltaScope PostgreSQL extractor, domain `spec` structs, audit corpus YAML, CLI/HTTP/MCP/public Go API tests, Markdown release docs.

		Metadata: map[string]any{
			"column":         "id",

	got := string(data)
	for _, want := range []string{

		`"metadata":`,
		`"column":"id"`,
		`"generated_when":"d"`,
		`"is_identity":true`,
