# v0.32.0 PostgreSQL Boundary Support-Readiness Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce an evidence-backed decision on whether PostgreSQL generated/identity boundaries should remain explicit unsupported outcomes or become a narrow real-support target in a later milestone.

**Architecture:** Work in an isolated branch. Start with a read-only inventory of generic PostgreSQL unsupported boundaries, then add characterization-only tests if needed for generated/identity support readiness. Finish with a decision report and release/roadmap docs. Do not change production behavior.

**Tech Stack:** Go tests, `pg_query_go/v6`, DeltaScope PostgreSQL extractor tests, SQL corpus YAML, Markdown release docs.
