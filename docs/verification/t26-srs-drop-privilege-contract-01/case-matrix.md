## Cross-cutting assertions (apply to every consuming row)

- Marker equality: `metadata["conditional_audit"]` must exist, type-assert
  to `string`, and equal `observed_account_new_session` exactly —
  missing key, `nil`, non-string, `""`, or another token never matches.
- Leakage scan: no serialized output (findings, gaps, diagnostics,
  errors) contains the account `app@%`, any `GRANT …` text, or
  observation SQL — raw evidence fields are `json:"-"`.
- Completed-statement immutability: rows with later scope termination
  (P7) assert the prefix statement's findings/gaps/owed are
  byte-identical after the tail statement runs.
- `L` attribution: `L=1` appears on every mode-on row whose batch names
  a qualifying audited statement, including B-arm rows — the load
  precedes arm selection (`metadata.go:341-352` before the loop).
- No `P` consumption ever mints findings on B/S0/S1, ever changes
  `srsExistenceStale`/`srsDepsStale` rules, or ever upgrades coverage.
