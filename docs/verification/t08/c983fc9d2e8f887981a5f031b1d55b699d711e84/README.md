# T08 verification evidence — c983fc9d

SHA-bound evidence for T08 column governance (issue #87,
mysql/tidb-ddl-completion milestone): normalized `FIRST|AFTER`
column-position facts, dialect-parametrized bounded multi-action
`ALTER TABLE` successors (MySQL accumulated working state vs TiDB
pre-statement premises), setter/position target existence rules,

TiDB auto-increment-removal tombstoning — proven against the frozen
172-case contract on all four anchors. Internal review evidence only —
not an external CI, reviewer, merge, or release claim.

This archive supersedes the deleted `6fb8e438` and `9c4fe175` archives.

amendments:

  successor instead of tombstoning on native `ERROR 8200`; the MySQL
  accumulated `AFTER` premise set missed sibling rename/drop deltas;
  the default-transition message collapsed into one string instead of
  the contract's frozen loses/gains/changes vocabulary. Fixed in
  `9c4fe175`.

  rechecked the working shape, so TiDB `RENAME a TO x, ADD x` /
  `CHANGE a TO x, ADD x` published a duplicate-name successor;

`probe.py`, `native-matrix.json`, `native-extra.json`, and the human-
readable `native-matrix.txt`. Confirmed, among others: TiDB clears an
