## Independent native probe

`native-probe/` — bounded per-anchor cells executed directly through
the mysql client during contract design (before product changes):
`probe.py`, `native-matrix.json`, `native-extra.json`, and the human-
readable `native-matrix.txt`. Confirmed, among others: TiDB clears an
omitted `DEFAULT` on `MODIFY` exactly like MySQL; MySQL validates
`ADD c2 AFTER c1` against same-statement accumulated state while TiDB
checks the pre-statement state; `SET DEFAULT ''` lands as
`COLUMN_DEFAULT=''` (distinct from NULL); `DEFAULT NULL` and an absent
default are catalog-indistinguishable.
