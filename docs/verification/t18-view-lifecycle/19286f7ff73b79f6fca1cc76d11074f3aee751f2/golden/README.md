# Golden artifacts

Final T16, T17, and T18 artifacts were generated on product commit
`19286f7ff73b79f6fca1cc76d11074f3aee751f2` and retain their original bytes and
execution paths. Policies are copied under each task's `policies/` directory.
Compiled CLI binaries are not archived.

`summary.json` verifies the artifact SHA-256, task and issue IDs, product and
build HEAD, CLI SHA-256, required/executed case sets, duplicate IDs, assertion
totals, container health, compose cleanup rc, and residual containers.
