# Domain Docs

## Layout

DeltaScope is a single-context repository. `CONTEXT.md` may be added at the
repository root when a maintained domain glossary is needed. Durable
architecture decisions live in `docs/decisions/`.

## Before Exploring

- Read root `CONTEXT.md` if it exists.
- Read decision records in `docs/decisions/` relevant to the area being
  changed.
- If those files do not exist, proceed without treating their absence as an
  error.

## Vocabulary and Decisions

Use terms defined in `CONTEXT.md` when it exists. If a proposed change
contradicts an accepted decision record, state the conflict explicitly instead
of silently overriding it.
