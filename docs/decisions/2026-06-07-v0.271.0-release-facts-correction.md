# v0.271.0 Release Facts Correction

**Date:** 2026-06-07
**Status:** Committed
**Affects:** Release consistency validator, v0.270.0 release notes, rules reference docs

## Advisory

Post-release verification of v0.270.0 found that release-facing documents and the consistency checker claimed "PostgreSQL ALTER TABLE rule count = 32" while `configs/deltascope.example.yaml` contains 53 distinct `ddl.pg.alter.*` entries. The "32" was correct at v0.170.0 but drifted as more ALTER TABLE config entries were added without updating the release fact.

## Decision

1. Rename the release fact from `pg_alter_table_rule_count` to `pg_alter_table_config_entries` for v0.270.0 onwards. The old name implied a semantic that no longer matches what is being counted.
2. Set the value to **53**, computed by counting lines matching `^  ddl\.pg\.alter\.` in `configs/deltascope.example.yaml`. This counts ALTER TABLE config entries only; entries like `ddl.pg.alter_aggregate.notice` (non-TABLE ALTER) are excluded by the regex.
3. Historical versions (v0.170.0–v0.260.0) retain `pg_alter_table_rule_count: 32` in the validator — they documented what was claimed at the time and are not being rewritten.

## Validator Gate

`_validate_pg_alter_table_config_entries` now:
- Counts `ddl.pg.alter.*` entries from `configs/deltascope.example.yaml` and asserts the count matches the declared fact value.
- Checks that v0.270.0 release notes contain the count in ALTER TABLE context.
- Skips gracefully if the config file is absent (test fixture compatibility).

## Non-Goals

- No parser support added.
- No new SQL audit rules.
- No audit verdict or finding semantic changes.
- No runtime output shape changes.
- No version bump or release surfaces for v0.271.0.

## Evidence

- `grep -c '^  ddl\.pg\.alter\.' configs/deltascope.example.yaml` → 53
- `grep -c '^  ddl\.pg\.alter_' configs/deltascope.example.yaml` → 49 (non-TABLE ALTER, not counted)
- v0.170.0 release notes: "Total PostgreSQL ALTER TABLE rule count rises to 32." — correct at the time.

## Verification

- `python3 scripts/test_verify_release_consistency.py` — all tests pass
- `VERSION=v0.270.0 python3 scripts/verify_release_consistency.py` — PASS with `pg alter table config entries 53`
