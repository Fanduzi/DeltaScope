## Context

v0.190.0 established a consolidated cross-dialect DDL coverage census. The MySQL/TiDB surface shows 25 and 27 `normalized_silent` forms respectively — statements that parse and normalize but emit no findings. These are the best next targets because they need no parser-library upgrades.

v0.190.0 baseline:

| Dialect | Total | Finding | Silent | Unsupported | Parser Error |
|---|---:|---:|---:|---:|---:|
| MySQL | 61 | 21 | 25 | 0 | 15 |
| TiDB | 54 | 18 | 27 | 0 | 9 |
| PostgreSQL | 285 | 274 | 6 | 0 | 5 |

## Decision

Promote all tracked MySQL/TiDB `normalized_silent` DDL forms to `finding_covered` in v0.200.0. Add notice-level lifecycle rules for each form using grouped rule constructors. No parser changes.

Target census:

| Dialect | Total | Finding | Silent | Unsupported | Parser Error |
|---|---:|---:|---:|---:|---:|
| MySQL | 61 | 46 | 0 | 0 | 15 |
| TiDB | 54 | 45 | 0 | 0 | 9 |
| PostgreSQL | 285 | 274 | 6 | 0 | 5 |

## Metadata No-Leak Contract

### Allowed bounded keys

`operation`, `action`, `dialect`, `table`, `old_table`, `new_table`, `index`, `index_type`, `database`, `procedure`, `user`, `role`, `privilege`, `object_type`, `policy`, `sequence`, `resource_group`

### Forbidden payloads

- Raw SQL or normalized SQL
- Procedure body text
- Password or authentication strings (`secret`, `new_secret`, `IDENTIFIED BY` payload)
- Full GRANT/REVOKE privilege payload beyond bounded privilege and object type
- Placement region constraint strings
- Sequence option values
- Parser AST dumps
- Runtime catalog state
- Lock or rewrite duration estimates

## Deferred Parser Errors

### MySQL (15 forms)

ALTER VIEW, ALTER PROCEDURE, CREATE FUNCTION, ALTER FUNCTION, DROP FUNCTION, CREATE TRIGGER, DROP TRIGGER, CREATE EVENT, ALTER EVENT, DROP EVENT, CREATE TABLESPACE, ALTER TABLESPACE, DROP TABLESPACE, CREATE RESOURCE GROUP, ALTER RESOURCE GROUP

### TiDB (9 forms)

ALTER VIEW, CREATE TRIGGER, DROP TRIGGER, CREATE FUNCTION, DROP FUNCTION, CREATE EVENT, DROP EVENT, ALTER TABLE TTL, ALTER TABLE LOCALITY

These require parser-library work and remain out of scope.

## Non-Goals

- No parser support changes.
- No full DDL support claim.
- No dialect parity claim.
- No runtime/catalog validation.
- No lock-duration or rewrite-duration estimation.
