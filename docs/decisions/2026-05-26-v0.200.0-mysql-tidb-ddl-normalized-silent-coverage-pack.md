# Decision: MySQL/TiDB DDL Normalized-Silent Coverage Pack

Date: 2026-05-26
Status: Accepted
Related milestone/version: v0.200.0
Related commits: afe3d3f (v0.190.0 baseline)
Related tests:
  `internal/application/audit/cross_dialect_ddl_coverage_census_test.go`
  `internal/application/audit/mysql_tidb_ddl_normalized_silent_metadata_census_test.go`

## Context

v0.190.0 established a consolidated cross-dialect DDL coverage census. The MySQL/TiDB surface shows 25 and 27 `normalized_silent` forms respectively — statements that parse and normalize but emit no findings. These are the best next targets because they need no parser-library upgrades.

v0.190.0 baseline:

| Dialect | Total | Finding | Silent | Unsupported | Parser Error |
|---|---:|---:|---:|---:|---:|
| MySQL | 61 | 21 | 25 | 0 | 15 |
| TiDB | 54 | 18 | 27 | 0 | 9 |
| PostgreSQL | 285 | 274 | 6 | 0 | 5 |

## Decision

Promote all tracked MySQL/TiDB `normalized_silent` DDL forms to `finding_covered` in v0.200.0. Add extractor normalization for standalone DDL forms and notice-level lifecycle/alter-action rules. No parser changes.

### Actual census outcome

| Dialect | Total | Finding | Silent | Unsupported | Parser Error |
|---|---:|---:|---:|---:|---:|
| MySQL | 61 | 46 | 0 | 0 | 15 |
| TiDB | 54 | 44 | 1 | 0 | 9 |
| PostgreSQL | 285 | 274 | 6 | 0 | 5 |

### TiDB residual normalized_silent (1 form)

`ALTER TABLE ... PLACEMENT POLICY` uses `AlterTableOption` AST type which maps to a generic `table_option` action. A notice rule for `table_option` would fire on all ALTER TABLE option changes (ENGINE, CHARSET, etc.), which is too broad. This form is deferred to a future extractor refinement that can distinguish PLACEMENT POLICY from other table options.

## Implementation

- **Extractors**: 18 new extraction functions in `internal/infrastructure/parser/tidb/extractor.go` for standalone CREATE/DROP INDEX, RENAME TABLE, ALTER DATABASE, procedures, users, roles, grants, revokes, placement policies, sequences, and resource groups. Added `AlterTableDropForeignKey` case to `alterActionName()`.
- **Rules**: `mysql_tidb_lifecycle_rules.go` (21 rules) and `mysql_tidb_alter_action_rules.go` (6 rules) in `internal/domain/rule/ddl/`.
- **DDLOperations**: 12 new constants in `internal/domain/spec/ddl.go`.
- **Policy/Config**: 27 new enabled rules at notice level.

## Metadata No-Leak Contract

### Allowed bounded keys

`operation`, `action`, `dialect`, `table`, `old_table`, `new_table`, `index`, `index_type`, `database`, `procedure`, `user`, `role`, `privilege`, `object_type`, `policy`, `sequence`, `resource_group`

### Forbidden payloads

- Raw SQL or normalized SQL
- Procedure body text
- Password or authentication strings (`secret`, `new_secret`, `IDENTIFIED BY` payload)
- Full GRANT/REVOKE privilege payload beyond bounded privilege and object type
- Placement region constraint strings
- Sequence option values
- Parser AST dumps
- Runtime catalog state
- Lock or rewrite duration estimates

Verified by `TestMySQLTiDBPromotedDDLMetadataCensus` with `ForbiddenSubstrings` assertions on sensitive forms.

## Deferred Parser Errors

### MySQL (15 forms)

ALTER VIEW, ALTER PROCEDURE, CREATE FUNCTION, ALTER FUNCTION, DROP FUNCTION, CREATE TRIGGER, DROP TRIGGER, CREATE EVENT, ALTER EVENT, DROP EVENT, CREATE TABLESPACE, ALTER TABLESPACE, DROP TABLESPACE, CREATE RESOURCE GROUP, ALTER RESOURCE GROUP

### TiDB (9 forms)

ALTER VIEW, CREATE TRIGGER, DROP TRIGGER, CREATE FUNCTION, DROP FUNCTION, CREATE EVENT, DROP EVENT, ALTER TABLE TTL, ALTER TABLE LOCALITY

These require parser-library work and remain out of scope.

## Non-Goals

- No parser support changes.
- No full DDL support claim.
- No dialect parity claim.
- No runtime/catalog validation.
- No lock-duration or rewrite-duration estimation.
