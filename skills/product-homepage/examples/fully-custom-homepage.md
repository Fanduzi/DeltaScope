# Example: Fully Custom Homepage

## User request
"Generate a completely new homepage for this product. Keep the product facts, but do not follow the current layout."

## Expected behavior
- gather repo facts first
- confirm fully custom mode and move directly to file strategy
- avoid inheriting the existing page structure
- create a fresh narrative and visual direction grounded in the product constraints
- use `frontend-design` for the visual branch unless the user requests otherwise
