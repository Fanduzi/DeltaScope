# Example: Replicate Current Homepage

## User request
"Use our current landing page as the base, keep the same overall structure, but tighten the copy and keep the approved sections."

## Expected behavior
- read the existing landing page first; if no current homepage or reference file exists, ask the user to provide one or switch to Fully Custom Homepage
- read README and relevant docs
- confirm product boundaries from repo facts
- ask whether to create a new file or overwrite a target file
- preserve the current homepage rhythm and section order unless a clear content issue requires a small reorder
- avoid introducing a radically different visual direction
